**Язык:** Python. Проверено на Python 3.14.3.

Основной файл — `hockey_solution.ipynb`. В нём выполнены все разделы задания:
сбор данных, проверки, построение ответа, разделение по годам, графики,
два ориентира, логистическая регрессия, один эксперимент и разбор пяти ошибок.
Ячейки выполнены, таблицы и графики уже видны при открытии.

Собраны 24 страницы и 582 строки. После соединения одинаковых команд
в соседних годах осталось 516 пар. Пропущенный 2004 год не соединяется через разрыв.
Медиана для целевого класса считается по всем командам будущего года,
до отбора пар. Равенство медиане относится к классу 0.

В обучении 338 строк, в validation и test — по 89.
Для выбора использовались только результаты validation. Эксперимент с прошлым
сезоном ухудшил ROC-AUC с 0,7720 до 0,7280, поэтому выбран исходный вариант.

Итоговая модель — логистическая регрессия с признаками `win_rate` и `goal_diff`.
Заполнение медианой и масштабирование входят в Pipeline и обучены только на train.
Параметры: `C=1.0`, `solver="lbfgs"`, `max_iter=1000`, `random_state=42`.
Порог классификации — 0.5. После выбора модель не переобучалась.

| Вариант на test | ROC-AUC | F1 | Accuracy |
|---|---:|---:|---:|
| Константа | 0,5000 | 0,0000 | 0,5281 |
| Текущий win_rate | 0,7404 | 0,6522 | 0,6404 |
| Выбранная регрессия | 0,7596 | 0,7059 | 0,6629 |

Небольшое преимущество относится к этой проверке. Трёх целевых лет недостаточно,
чтобы утверждать, что модель всегда будет лучше простого ориентира.

## Как запустить

Открывать и запускать ноутбук нужно из папки с этими файлами.
При обычном запуске данные читаются из CSV, доступ к сайту не нужен.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run_notebook.py
```

Для просмотра и изменения можно открыть `hockey_solution.ipynb` в VS Code
с поддержкой Jupyter или в другом редакторе ноутбуков, выбрав Python из `.venv`.
Результаты в файле можно посмотреть и без повторного выполнения.

Полное решение можно также запустить обычным Python-скриптом:

```bash
python hockey_solution.py
```

Скрипт выводит таблицы в терминал и сохраняет графики и результаты в `results/`.
Файл `hockey_solution.ipynb` при этом не изменяется.

Чтобы заново собрать сайт:

```bash
python collect_data.py
python run_notebook.py
```

Либо поменять `COLLECT_AGAIN = False` на `True` в ячейке 1.1.
Новый сбор заменяет CSV и журнал. Если источник изменится, числа в текстовых
ответах потребуется обновить после нового выполнения.

## Как устроено решение простыми словами

Одна строка — одна команда за один сезон. `target` — правильный ответ:
была ли команда в следующем году строго выше середины лиги по доле побед.
Модель видит только текущую долю побед и разность голов и выдаёт число от 0 до 1.
Если число не меньше 0.5, ставим прогноз 1.

Train — старые годы, на которых модель учится. Validation — следующие годы,
на которых выбираем вариант. Test — последние годы для итоговой проверки.
Данные будущего сезона нужны для правильного ответа и разбора ошибок,
но среди признаков их нет.
